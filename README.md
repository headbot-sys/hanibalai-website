# Hannibal AI

Marketing site for Hannibal AI, plus **Forge** — a self-hosted workstation management platform (RMM/MDM).

## Forge RMM

See [`forge/README.md`](forge/README.md) for install, agent enrollment, and console usage.

```bash
cd forge
npm install && npm run install:all
npm run seed
npm run dev
```

Open http://localhost:5173 (console) — API on http://localhost:8787
